# Edit technical prose

The goal is text that reads as if a careful engineer wrote it. Do not add personality. Remove the patterns that identify generic AI text.

## Do not change

Do not change code or text in code format. Do not change identifiers, paths, URLs, endpoints, field names, numbers, units, versions, error messages, table structure, or diagram labels. Do not change decisions, constraints, or warnings. If a change in words can change the meaning, keep the original text.

## Remove or replace

- Filler at the start or end of text. Examples: "In today's fast-paced world," "It's important to note that," "In conclusion," and "Let's dive in."
- Promotional and vague words. Examples: robust, seamless, powerful, cutting-edge, leverage, streamline, holistic, and game-changing. Replace each word with the specific property, or remove it.
- Many qualifiers together, such as "may potentially perhaps." Keep one qualifier only where the uncertainty is real. Tell what the uncertainty is.
- Summaries that only repeat the section before them.
- Fixed patterns. Examples: each section starts with a definition, each list has exactly three items, rhetorical questions, and "not just X but Y."
- Too many dashes, bold words, bullets, and headings where one sentence is sufficient.
- Passive voice that hides the actor, such as "the request is processed." Tell who or what does the action.

## Use

- Specific words in place of general words: numbers, names, and conditions.
- Short, direct sentences. Use different sentence lengths.
- One term for each concept. Use that term in all locations.
- Imperative mood for procedures. Present tense for behavior.
- Simple words, such as "use," "start," and "need," in place of "utilize," "commence," and "necessitate."
- Direct statements for decisions and trade-offs: "We chose X because Y. The cost is Z."

## Procedure

1. Edit one section at a time.
2. Keep headings that help readers find information. Remove headings that only label filler text.
3. Do a last check. Compare the code blocks, numbers, and identifiers to the original to make sure that no technical content changed. Then read the text again to find repeated sentence patterns.
