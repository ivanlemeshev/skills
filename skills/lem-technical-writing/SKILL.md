# Technical writing

Use this skill when writing or editing technical documentation and code comments.

Always use ASD-STE100 Simplified Technical English in all comments and documentation.

Keep each Markdown prose paragraph on one source line. Preserve structural line breaks in lists, tables, and code blocks.

Format Markdown tables with aligned columns, consistent cell padding, and a header separator row.

Keep only important information. Use simple words and short sentences. Use one idea per sentence. Prefer active voice and direct statements. Remove repetition, filler, and obvious explanations.

Preserve the user's meaning, technical terms, code identifiers, and required detail. Improve clarity without changing intent.

Write comments only for intent, constraints, or non-obvious behavior. Keep comments close to the code they explain.

Before finishing, read the text once for unnecessary words and once for unclear meaning.
